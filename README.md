# Mini project — Waderstop
Generative music piece for gameplay (OpenMusic 7.6)

Waderstop is a cozy video game where the player travels through quiet, everyday spaces. To accompany it, an algorithmically generated piece was composed in OpenMusic (OM) 7.6, with a bright and rhythmic character, designed for clean looping in gameplay.

The music integrates with the video while maintaining the original sounds of the game (footsteps, dripping, ambient noise): the title music was separated/isolated and our soundtrack was mixed on top, preserving the effects.

## Objective

- Compose an original piece (without using pre-recorded musical material such as wav/midi/mp3) consistent with the game.

- Duration ≥ 2 minutes and ≥ 1 minute of fresh material.

- Implement with OM programming concepts: randomness, cycles, data structures, temporal concatenation, input/output typing.

## Implementation

* OpenMusic 7.6 (music generation and structure).

* Audacity (final mix with game SFX and normalization).

* Clipchamp (Editor for assembling gameplay + final audio).
